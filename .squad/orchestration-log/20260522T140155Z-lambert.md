## Technical Decisions

1. **Payment CTA strategy** — Frontend-only "coming soon" UX avoids blocking consultation flows while waiting for payment gateway selection
2. **Notification service centralization** — Single source of truth via Zustand store reduces prop-drilling and enables header-level badge without tight coupling to screens
3. **Video service layering** — Backend-first with localStorage fallback prevents dev dependency on WebRTC while maintaining production readiness
4. **Permission UX** — Demo alert first-launch allows end-to-end testing of reminder flows without actual iOS/Android permission APIs
