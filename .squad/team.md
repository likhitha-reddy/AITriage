# AITriage — Squad Team

## Project Context

**Project:** AITriage — AI-powered healthcare triage platform
**Owner:** gsreddy
**Description:** AI healthcare triage app (similar to Tata 1mg / Apollo 247) with AI-driven patient symptom analysis, image-based diagnosis support, doctor consultation matching, prescription management, and progress tracking. Subscription-based with free perks. Initial focus: mental health and dermatology markets.

**Stack:**
- Frontend/Mobile: React Native
- Backend: Python (FastAPI)
- AI/ML: Python (LLM APIs + image analysis)
- Database: PostgreSQL
